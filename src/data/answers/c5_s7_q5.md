# AI Trả lời Thông tin Không có trong Tài liệu

## ⚡ Tóm tắt ngắn (30s)
* **Symptom**: AI hallucinates — answers with facts not in retrieved context.
* **Causes**:
  1. Retrieval miss (no relevant chunks) but model still tries.
  2. Prompt not strict enough.
  3. Model "knows" from prior training, overrides context.
  4. Citation not enforced.
* **Quick fix**: strict prompt + similarity threshold + citation validation.
* **Long-term**: improve retrieval (chunk size, embedding, rerank), LLM judge for faithfulness.

---

## 🔍 Triage

### Step 1: Reproduce
- Replay user query.
- Inspect retrieved chunks.
- Compare with response.

### Step 2: Diagnose
| Pattern | Cause |
| :--- | :--- |
| Top-K sim < 0.5 | Retrieval miss → model bịa |
| Top-K relevant but answer extras | Prompt weak |
| Answer contradicts context | Model ignores |

### Step 3: Fix
- Increase similarity threshold (refuse if low).
- Strengthen prompt: "ONLY answer from context, else refuse".
- Citation enforcement.
- LLM judge in async.

## 💻 Strict prompt

```java
private static final String STRICT = """
    Bạn là trợ lý CHỈ trả lời từ CONTEXT.
    
    QUY TẮC TUYỆT ĐỐI:
    1. Nếu CONTEXT không đủ → trả "Tôi không tìm thấy trong tài liệu".
    2. Mỗi claim factual PHẢI kèm citation [doc:X chunk:Y].
    3. KHÔNG suy diễn, KHÔNG dùng kiến thức ngoài.
    
    Few-shot ví dụ từ chối:
    Q: "Người 70 tuổi đăng ký được không?"
    Context: "Chấp nhận 18-65 tuổi."
    A: "Theo tài liệu, hệ thống chấp nhận 18-65 tuổi [doc:5]. Tôi không tìm thấy thông tin về người trên 65 tuổi."
    """;
```

## 💻 Similarity threshold

```java
public String answer(String q, List<Chunk> retrieved) {
    if (retrieved.isEmpty() || retrieved.get(0).similarity() < 0.55) {
        return "Tôi không tìm thấy thông tin liên quan trong tài liệu.";
    }
    // proceed
}
```

## 💻 Citation validator

```java
public ValidationResult validate(String response, List<Chunk> retrieved) {
    var validIds = retrieved.stream()
        .map(c -> "[doc:" + c.docId() + " chunk:" + c.chunkIdx() + "]")
        .collect(Collectors.toSet());
    
    var pattern = Pattern.compile("\\[doc:[^\\]]+\\]");
    var matcher = pattern.matcher(response);
    while (matcher.find()) {
        if (!validIds.contains(matcher.group())) {
            return ValidationResult.invalid("Fake citation: " + matcher.group());
        }
    }
    return ValidationResult.valid();
}
```

## ⚠️ Interviewer

**"Eliminate hallucination 100%?"**
No. RAG reduces 60-80%; combined defense ~95%. Never 100%. Design system to:
1. Refuse rather than make up.
2. Flag uncertain.
3. Human escalation option.
4. Audit + iterate.
