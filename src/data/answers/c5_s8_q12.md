# Trade-off Prompt-based Rule vs Code-based Rule

## ⚡ Tóm tắt ngắn (30s)
* **Prompt rule**: "Always refuse if user asks X". Flexible, easy iterate.
* **Code rule**: `if (input.contains(X)) return refuse;`. Deterministic, fast.
* **Trade-off**:
  - Prompt: LLM may sometimes bypass (~1-5% jailbreak success).
  - Code: rigid but reliable.
* **Best**: code for critical (compliance), prompt for soft (tone, helpful).

---

## 💻 Combination example

```java
public Response handle(String input) {
    // Code rule: hard compliance
    if (containsRestrictedTopic(input)) {
        return Response.refuse("Topic not allowed.");
    }
    
    // Prompt rule: soft tone
    return llm.chat(STRICT_TONE_PROMPT, input);
}
```

---

## 📊 Use case

| Rule type | Use code | Use prompt |
| :--- | :--- | :--- |
| Compliance "no medical advice" | ✓ regex blocker | + prompt confirm |
| Tone "be friendly" | ✗ | ✓ |
| Action "refuse if amount > $X" | ✓ | + prompt |
| Refuse off-topic | helpful filter | prompt main |
