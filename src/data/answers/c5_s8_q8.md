# Trade-off Automation vs Human Approval

## ⚡ Tóm tắt ngắn (30s)
Refer c5_s4_q9.

* **Automation win**: speed, scale, consistency, cost.
* **Human approval win**: safety, accountability, edge cases, compliance.
* **Decision matrix by action level**:
  - Level 0-1 (read, low write): auto.
  - Level 2-3 (write affecting others): notify or approval.
  - Level 4+ (irreversible, high value): mandatory approval.
* **Goal**: maximize automation where safe, gate critical only.

---

## 📊 Decision by action

| Action | Confidence high | Confidence low |
| :--- | :---: | :---: |
| Read | Auto | Auto + log |
| Update profile | Auto | Notify |
| Send email | Auto rate-limit | Approval |
| Refund < $50 | Auto + audit | Approval |
| Refund > $500 | 1-eye | 2-eye |
| Delete account | NEVER auto | Manager approve |

## 💻 Conditional approval

```java
public ActionDecision decide(Action action, Confidence conf) {
    Risk risk = riskScorer.score(action);
    
    if (risk == HIGH) return ActionDecision.requireApproval();
    if (risk == MEDIUM && conf == LOW) return ActionDecision.requireApproval();
    if (risk == MEDIUM) return ActionDecision.notify();
    return ActionDecision.autoExecute();
}
```

## ⚠️ Interviewer

**"Customer impatient with approval delays. Compromise?"**
1. Auto-approve for trusted users (history + tier).
2. Faster review SLA (30 min target).
3. Self-service: user pre-approves patterns.
4. Mobile approval app.
5. AI risk scoring: only escalate high-risk.
