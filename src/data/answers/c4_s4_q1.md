# Decision Bank — 10 Quyết định Kỹ thuật Đã Gặp

## ⚡ Tóm tắt ngắn (30s)
* **Mục đích**: chuẩn bị 10 quyết định kỹ thuật bạn từng làm, mỗi cái cover:
  - **Options** considered.
  - **Trade-off** between them.
  - **Constraint** that pushed decision.
  - **Monitor** how you'd verify if right.
* **Format**: 2-3 min telling per decision.
* **Categories đa dạng**: tech stack, architecture, hiring, process.

---

## 💻 Template per decision

```markdown
# Decision: [Title]

## Context
When, where, what triggered.

## Options
1. A: brief.
2. B: brief.
3. C: brief.

## Trade-offs
| Criteria | A | B | C |
| :--- | :---: | :---: | :---: |

## Constraints
What forced choice.

## Decision
Chose [option] because [reason].

## How I monitor
What metric would tell me if right.

## Outcome
Looking back, was it right? Why?
```

---

## 💻 Example: NoSQL vs SQL

```markdown
# Decision: NoSQL vs SQL for new feature

## Context
2023, building user activity feed feature. 1M users, 100 events/day each.

## Options
1. PostgreSQL with partitioning.
2. Cassandra time-series.
3. ElasticSearch.

## Trade-offs
| Criteria | PG | Cassandra | ES |
| Write throughput | Med | High | Med |
| Read latency | Low | Med | Low |
| Ops complexity | Low | High | Med |
| Schema flex | Low | Med | High |
| Aggregation | Strong | Weak | Strong |

## Constraints
- Team has 4 engineers, 1 has Cassandra exp.
- 3-month timeline.
- Need fast query for "user's last N events".

## Decision
Chose Postgres with monthly partition.
Reason: team expertise; pattern works for 1M users (~30GB/year); aggregation easy.

## Monitor
- p99 query latency on `events` table.
- Partition size growth.
- If exceed 200GB, reconsider.

## Outcome
6 months later: 80GB data, p99 100ms. Right choice.
Cassandra would have added ops burden not justified at this scale.
```

## ⚠️ Common Mistakes & Pro Tips

1. **"It just worked"**: no reasoning shown.
2. **No trade-off table**: senior expects structured.
3. **Hindsight bias**: claim everything right.
4. **No monitor**: shows lack of accountability.

**Pro tip**: practice explaining each decision in 2-3 min. Interviewer asks "tell me about a hard decision" — you have story ready.
