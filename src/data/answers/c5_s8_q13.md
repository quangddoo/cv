# Trade-off Speed Rollout vs AI Governance

## ⚡ Tóm tắt ngắn (30s)
* **Speed rollout**: competitive advantage, learn fast.
* **AI governance**: safety, compliance, reduced risk.
* **Balance**:
  - Minimum viable governance (MVG) for early stage.
  - Mature later with usage.
* **Non-negotiable**: security review, prompt injection defense, audit, rollback.
* **Negotiable**: extensive eval, multiple model providers, advanced monitoring.

---

## 📊 Phase appropriate governance

| Phase | Minimum needed |
| :--- | :--- |
| PoC | Internal only, no PII, simple monitor |
| Beta | Security review, opt-in users, basic eval |
| Production | Full security + eval + rollback + audit + on-call |
| Mature | Multi-provider, fine-tune ops, advanced eval, compliance audits |

---

## ⚠️ Interviewer

**"Pressure: ship in 2 weeks, no time for full governance. What's minimum?"**
1. NEVER skip: prompt injection defense, output filter, kill switch, basic audit.
2. Can defer: eval suite (initial 30 cases ok), multi-provider (single OK), fine-tune.
3. Phase rollout: internal → 5% → 50% → 100% with metric gates.
4. Hire/borrow security review (1 day).
5. Document accepted risks for later.
