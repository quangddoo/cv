# Bắt đầu bài coding lạ — Clarify, brute force, rồi refine
## Câu trả lời mẫu
Tôi restate bài toán bằng ví dụ nhỏ, hỏi input constraint, duplicate, ordering, empty case và expected behavior khi input không hợp lệ. Tôi nêu một brute-force solution đơn giản trước để xác nhận hiểu đúng, phân tích complexity, sau đó tìm pattern phù hợp như hash map, two pointers, BFS/DFS, heap, binary search hoặc dynamic programming.

Tôi nói suy luận trước khi code: invariant là gì, data structure lưu thông tin nào và mỗi bước làm giảm không gian tìm kiếm ra sao. Tôi implement incrementally, chạy qua happy path và edge case, rồi mới tối ưu nếu constraint yêu cầu. Nếu có nhiều cách, tôi chọn cách dễ chứng minh và maintain trước khi tối ưu vi mô.

**Tín hiệu cần thể hiện:** problem solving có cấu trúc, giao tiếp rõ và không nhảy thẳng vào code khi chưa chốt contract.
