# Khi nào Dùng External Model Provider

## ⚡ Tóm tắt ngắn (30s)
* **External API (OpenAI/Anthropic/Gemini) khi**:
  1. **Speed-to-market**: 1 ngày integrate vs 1 tháng self-host.
  2. **Quality frontier**: latest model only on provider.
  3. **<10M token/day**: cheaper than self-host TCO.
  4. **No MLOps team**.
  5. **Features-new**: vision, audio, tool calling.
  6. **Auto-scale**: provider handles spike.
* **Combine**: Bedrock cho compliance + OpenAI cho features mới.

---

## 📊 Provider comparison (May 2026)

| Provider | Strength | Best for |
| :--- | :--- | :--- |
| OpenAI | Function calling format, eco | General + tools |
| Anthropic | Reasoning, prompt caching | Complex tasks |
| Google Vertex | Long context (1M), multimodal | Cross-doc analysis |
| AWS Bedrock | Compliance, multi-model | Enterprise |
| Azure OpenAI | Enterprise, regional | Microsoft stack |

## ⚠️ Interviewer

**"DPA/SLA negotiable?"**
1. Enterprise tier: yes, custom DPA, no-training, retention 0.
2. Standard tier: standard terms.
3. Managed (Bedrock/Azure): cloud provider DPA inherited.
4. Read carefully sub-processor list.
5. Audit rights: critical for compliance.
