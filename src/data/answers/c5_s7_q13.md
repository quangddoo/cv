# AI Feature làm Lộ Thông tin Nhạy cảm trong Log

## ⚡ Tóm tắt ngắn (30s)
* **Severity HIGH**: PII in logs accessible to engineers = breach risk.
* **Immediate action**:
  1. Stop logging full content (config update).
  2. Audit who accessed logs.
  3. Purge if possible (Datadog retention).
  4. Implement redaction at source.
* **Long-term**: Presidio integration, tiered logging.

## 💻 Emergency redact

```java
// Logger filter for in-flight logs
@Component
public class PiiRedactor {
    private static final Pattern EMAIL = Pattern.compile("[\\w.+-]+@[\\w-]+\\.[\\w-.]+");
    private static final Pattern PHONE = Pattern.compile("\\+?\\d[\\d -]{7,15}");
    
    public String redact(String text) {
        return text
            .replaceAll(EMAIL.pattern(), "<EMAIL>")
            .replaceAll(PHONE.pattern(), "<PHONE>");
    }
}

// MDC filter or appender
public class RedactingAppender extends AppenderBase<ILoggingEvent> {
    private final PiiRedactor redactor = new PiiRedactor();
    
    @Override
    protected void append(ILoggingEvent event) {
        String redacted = redactor.redact(event.getFormattedMessage());
        // emit redacted
    }
}
```

## 📊 Tiered logging

| Tier | Content | Access |
| :--- | :--- | :--- |
| 1 (Always-on) | Metadata only | Engineers |
| 2 (Sampled 1%) | Redacted content | On-call, with reason |
| 3 (Opt-in) | Full | User + privacy team |

3. Quantify exposure.

6. Audit access during exposure window.
