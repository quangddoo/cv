# AI-Generated Email/Message Sai Tone — Guardrail

## ⚡ Tóm tắt ngắn (30s)
* **Symptom**: AI sent message with wrong tone (too casual, offensive, off-brand). Customer complaints.
* **Defense layers**:
  1. **Template-driven** (not full generation): use templates + LLM fills variables.
  2. **Tone classifier**: LLM judge before send.
  3. **Length/format constraint**: cap variables.
  4. **Human review** for high-risk messages.
  5. **A/B test** new templates before mass send.
* **Long-term**: brand voice fine-tuning.

---

## 🔍 Defense

### 1. Template-driven (refer c5_s6_q19)
```
Hi {{name}},

Order {{id}} status: {{personalized_note}}.

Thanks,
ABC
```
LLM only fills `{{personalized_note}}` (1-2 sentences, constrained).

### 2. Tone classifier
```python
def check_tone(text: str) -> bool:
    resp = judge.chat(
        f"Brand tone: friendly, professional, concise.\n"
        f"Message: {text}\n"
        f"Does it match brand? yes/no with reason."
    )
    return "yes" in resp.lower()
```

### 3. Length cap
```java
public String generateNote(Context ctx) {
    String note = llm.chat(...).content();
    if (note.length() > 200) note = note.substring(0, 200);
    if (containsForbiddenPhrase(note)) note = fallback(ctx);
    return note;
}
```

### 4. Human review for mass send
```
< 100 recipients: auto-send.
100-10k: sample 5%, human review.
> 10k: human approve template + content.
```
