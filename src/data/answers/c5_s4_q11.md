# Giới hạn Số bước Agent được Chạy

## ⚡ Tóm tắt ngắn (30s)
* **Hard step cap** là safety net **không thể bỏ qua**. Default: 10-20 steps cho hầu hết agent.
* **Cách set step limit theo use case**:
  * Simple Q&A: 3-5 steps.
  * Multi-tool support: 10-15.
  * Complex research/code: 20-30.
* **Strategies khi đạt limit**:
  1. **Hard abort**: return error.
  2. **Graceful summarize**: agent buộc trả final answer dù chưa hoàn thành.
  3. **Escalate**: handoff cho human với context đã có.
* **Beyond just step count**: combo với cost cap, time cap.
* **Thảm họa**: Agent task "research market" không cap → 50 steps, $30. Senior fix: cap 20 steps + graceful summarize at limit.

## 🔍 Implementation

### 1. Hard cap pattern

```java
public AgentResult run(AgentTask task) {
    for (int step = 0; step < task.maxSteps(); step++) {
        // ... execute step
        if (done) return result;
    }
    return AgentResult.maxStepsReached(history);
}
```

### 2. Graceful at limit

```java
if (step >= MAX_STEPS - 1) {
    // Inject "finalize" instruction
    messages.add(new Message("user",
        "You've used most of your steps. Provide BEST FINAL ANSWER now from current info."));
}
```

### 3. Soft limit + warning

```java
if (step >= 0.8 * MAX_STEPS) {
    log.warn("Agent {}/{} steps, soft warning", step, MAX_STEPS);
    // Optionally hint agent to wrap up
}
```

## 💻 Complete example

```java
@Service
public class StepLimitedAgent {

    public AgentResult run(String userMsg, int maxSteps) {
        List<Message> messages = List.of(new Message("user", userMsg));
        
        for (int i = 0; i < maxSteps; i++) {
            boolean isLast = (i == maxSteps - 1);
            
            // Inject finalize on last step
            if (isLast) {
                messages = addFinalizationHint(messages);
            }
            
            var resp = llm.chat(messages, tools);
            
            if (resp.stopReason() == END_TURN) {
                return AgentResult.success(resp.text(), i + 1);
            }
            
            if (isLast) {
                // Force final
                var finalResp = llm.chat(messages, /*no tools*/ List.of());
                return AgentResult.success(finalResp.text(), i + 1);
            }
            
            // Execute tool
            var toolResult = executeTool(resp.toolCall());
            messages = appendToolResult(messages, resp.toolCall(), toolResult);
        }
        
        return AgentResult.fallback("Could not complete in " + maxSteps + " steps");
    }
}
```

## ⚠️ Gotchas + Interviewer

1. **Cap quá thấp** → legitimate task abort. A/B test step limit on golden set.
2. **Soft limit nhiều quá** → effectively no limit.
3. **Graceful logic bug** → vẫn không trả final.

**Interviewer: "Agent đạt step limit. UX next step?"**
1. **Best effort answer**: từ thông tin đã có.
2. **Show user options**: "I've gathered X, Y. Want me to continue? Use [continue] button (uses more credits)".
3. **Escalate**: handoff to human với context.
4. **Log for analysis**: tại sao agent cần > limit? Tune limit hoặc improve prompt.
