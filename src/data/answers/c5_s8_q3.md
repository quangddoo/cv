# Khi nào Chọn Model Lớn thay vì Model Nhỏ

## ⚡ Tóm tắt ngắn (30s)
* **Spectrum**: gpt-4o-mini ($0.15/1M) → Sonnet ($3) → Opus ($15). Choose by task.
* **Model lớn khi**:
  1. **Complex reasoning**: multi-step logic, math, code review.
  2. **Long context** + cross-section synthesis.
  3. **Critical quality**: legal, medical, high-stakes.
  4. **Few-shot generalization** weak in smaller model.
* **Model nhỏ khi**:
  1. **Simple classification**: spam, intent, label.
  2. **High volume**: cost-sensitive.
  3. **Low-latency**: <500ms p99.
  4. **Narrow scope**: well-defined task.
* **Pattern**: hierarchical — small model first, escalate to big if needed.

---

## 📊 Model tier guide

| Task | Recommended |
| :--- | :--- |
| Simple classify | Haiku 4.5 / gpt-4o-mini |
| FAQ retrieval | Haiku |
| Summarize short | Haiku |
| Multi-step reasoning | Sonnet |
| Code generation | Sonnet |
| Legal/medical analysis | Opus |
| Complex agent | Opus |
| Translation | Sonnet (multilingual) |

## 💻 Tier-based routing

```java
public String selectModel(TaskComplexity complexity, String tier) {
    if (tier.equals("free")) {
        return "claude-haiku-4-5";  // always cheap
    }
    return switch (complexity) {
        case SIMPLE -> "claude-haiku-4-5";
        case MEDIUM -> "claude-sonnet-4-6";
        case COMPLEX -> "claude-opus-4-7";
    };
}
```

## ⚠️ Interviewer

**"Cost giảm 80% bằng route smart?"**
1. Classifier route by task type/complexity.
2. Most simple tasks → Haiku (90% of volume).
3. Complex reserved (10%) → Opus.
4. A/B test quality per route.
5. Monitor: misroute (small model failed → escalate).
