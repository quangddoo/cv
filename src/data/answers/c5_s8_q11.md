# Trade-off Agent Linh hoạt vs Workflow Deterministic

## ⚡ Tóm tắt ngắn (30s)
Refer c5_s4_q15.

* **Agent (LLM)**: flexible, adapts. Cost + latency high. Non-deterministic.
* **Workflow (code)**: predictable, fast, cheap. Inflexible for novel input.
* **Hybrid**: 80% workflow (defined paths) + 20% agent (edge cases).
* **Decision**: task định hình → workflow; fuzzy → agent.

---

## 📊 Compare

| Aspect | Agent | Workflow |
| :--- | :---: | :---: |
| Adaptability | ✓ | ✗ |
| Predictability | ✗ | ✓ |
| Cost | $0.05/req | $0 |
| Latency | 3-10s | 50-300ms |
| Debug | Hard | Easy |
| Compliance certify | Hard | Easy |

---

## ⚠️ Interviewer

**"Build returns flow. Agent or workflow?"**
- Returns flow has clear states: request → eligibility check → approve → ship label.
- Workflow code. Each step has rules.
- Agent only for "edge case escalation" when rule doesn't match.
- 90% workflow, 10% agent.
