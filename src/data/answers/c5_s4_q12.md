# Log và Audit Hành động của Agent

## ⚡ Tóm tắt ngắn (30s)
* **Agent audit log** = ghi mọi action agent làm: tool call, args, result, user_id, timestamp, reasoning. **Bắt buộc** cho compliance, debug, security forensic.
* **5 fields PHẢI log**:
  1. **request_id / session_id**: trace toàn bộ session.
  2. **user_id (hashed)**: ai trigger.
  3. **agent_step_idx**: thứ tự trong session.
  4. **tool_name + args (redacted PII)**: action gì.
  5. **result + status**: kết quả.
* **Optional but useful**: LLM reasoning, cost, latency, approval_id.
* **Storage tiers**:
  * Hot (24h): Elasticsearch/Datadog cho debug realtime.
  * Warm (90 days): S3 + Athena.
  * Cold (year+): Glacier for compliance.
* **Thảm họa thực chiến**: Agent execute refund nhưng customer claim "not received". Không log → không chứng minh được. Auditor fine. Senior fix: structured logging mọi action; immutable storage.

## 💻 Code

### 1. Audit service

```java
@Service
public class AgentAuditService {
    private final KafkaTemplate<String, AuditEvent> kafka;
    private final ObjectMapper mapper = new ObjectMapper();

    public void recordToolCall(AgentContext ctx, ToolCall call, ToolResult result, long latencyMs) {
        AuditEvent event = AuditEvent.builder()
            .logId(UUID.randomUUID().toString())
            .timestamp(Instant.now())
            .sessionId(ctx.sessionId())
            .userIdHash(hash(ctx.userId()))
            .tenantId(ctx.tenantId())
            .agentProfile(ctx.profile())
            .stepIdx(ctx.stepCount())
            .eventType("tool_call")
            .toolName(call.name())
            .toolArgsRedacted(redact(call.args()))
            .approvalId(ctx.approvalId())
            .resultStatus(result.status())
            .resultSummary(truncate(result.summary(), 200))
            .latencyMs(latencyMs)
            .costUsd(ctx.lastCost())
            .traceId(ctx.traceId())
            .agentReasoning(truncate(ctx.lastReasoning(), 500))
            .build();
        
        // Async to Kafka → fan-out to ES, S3, Datadog
        kafka.send("agent.audit", event);
    }

    private Map<String,Object> redact(Map<String,Object> args) {
        var copy = new HashMap<>(args);
        copy.replaceAll((k, v) -> isSensitive(k) ? "<REDACTED>" : v);
        return copy;
    }

    private boolean isSensitive(String key) {
        return key.matches("(?i).*(password|ssn|card|email|phone).*");
    }

    private String hash(String input) { /* SHA-256 */ return ""; }
    private String truncate(String s, int max) { return s.length() > max ? s.substring(0, max) : s; }
}
```

### 2. Immutable storage S3

```java
@Service
@KafkaListener(topics = "agent.audit")
public class AuditPersister {
    private final S3Client s3;

    public void persist(AuditEvent event) {
        String key = String.format("audit/%s/%s.json",
            LocalDate.now(), event.logId());
        
        s3.putObject(b -> b
            .bucket("agent-audit-immutable")
            .key(key)
            .objectLockMode(ObjectLockMode.COMPLIANCE)  // immutable
            .objectLockRetainUntilDate(Instant.now().plus(Duration.ofDays(2555))),  // 7 years
            RequestBody.fromString(toJson(event)));
    }
}
```

### 3. Query audit log

```sql
-- Athena query on S3 audit logs
SELECT timestamp, tool_name, tool_args_redacted, result_status
FROM agent_audit_log
WHERE user_id_hash = 'sha256_of_alice'
  AND timestamp BETWEEN TIMESTAMP '2026-05-01' AND TIMESTAMP '2026-05-31'
  AND tool_name = 'refund_order'
ORDER BY timestamp DESC;
```

## ⚠️ Gotchas + Interviewer

1. **PII trong logs**: redact at source.
2. **Log loss**: Kafka durability + retry; dead-letter queue.
3. **Tamper-evident**: immutable storage (S3 Object Lock), digital signatures.

**Interviewer: "Auditor request reconstruct mọi action user X làm. Bạn handle thế nào?"**
1. **Query**: filter by `user_id_hash(X)` cross all time.
2. **Chain reconstruction**: order by timestamp, group by session_id.
3. **Privacy**: ensure auditor có legal basis trước khi share.
4. **Export format**: CSV/JSON với redacted PII, but show actions.
5. **Verify integrity**: checksum/signature trên log records.
6. **SLA**: response within 7 days với court order; standard request 30 days.
