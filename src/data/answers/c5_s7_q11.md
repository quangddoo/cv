# User dùng Prompt cực dài làm Cost tăng cao

## ⚡ Tóm tắt ngắn (30s)
* **Pattern**: user pastes 50k token document, asks "explain in detail", costs $5/request.
* **Prevention**:
  1. **Input token cap**: reject if > N token.
  2. **Max_tokens cap on output**.
  3. **Per-user quota** (daily token).
  4. **Cost cap per request**.
  5. **Truncate long input**: if exceed, truncate to last N tokens.
  6. **Summarize instead of full**: for long input, redirect to summarization endpoint.
* **Communication**: tell user upfront about limits.

---

## 💻 Guard implementation

```java
@Service
public class TokenBudgetGuard {
    private static final int MAX_INPUT = 8000;
    private static final int MAX_OUTPUT = 1500;
    
    public void validate(String userId, String prompt) {
        int tokens = tokenCounter.count(prompt);
        if (tokens > MAX_INPUT) {
            throw new IllegalArgumentException(
                "Prompt quá dài: " + tokens + " token (max " + MAX_INPUT + "). " +
                "Hãy chia nhỏ hoặc dùng /summarize endpoint."
            );
        }
        if (!quota.reserve(userId, tokens + MAX_OUTPUT)) {
            throw new QuotaExceededException();
        }
    }
}
```
