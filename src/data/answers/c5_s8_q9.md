# Trade-off Logging để Debug vs Privacy

## ⚡ Tóm tắt ngắn (30s)
* **Logging full content**: easy debug, compliance violation, PII risk.
* **Minimal logging**: privacy safe, hard to debug.
* **Solution**: tiered logging (refer c5_s2_q9).
  - Tier 1 always: metadata only.
  - Tier 2 sampled 1%: redacted content, encrypted.
  - Tier 3 opt-in: full, TTL 7d.

---

## 📊 Tiered logging

| Tier | Content | Access | Purpose |
| :--- | :--- | :--- | :--- |
| 1 (always) | Metadata (id, token, latency) | Engineers | Performance |
| 2 (1% sample) | Redacted prompt/response | On-call w/ approval | Debug |
| 3 (opt-in) | Full content TTL 7d | User + privacy | Deep debug |

---

## ⚠️ Interviewer

**"Customer reports bug. Need full prompt. Privacy?"**
1. Default tier 1+2 covers most.
2. If unable to repro from tier 2 → ask customer consent for tier 3.
3. User opts in for specific session.
4. Time-limited (auto-purge 7d).
5. Access logged.
