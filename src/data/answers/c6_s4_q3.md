# Phân tích và cải thiện complexity — Tối ưu theo constraint
## Câu trả lời mẫu
Tôi định nghĩa n và các biến kích thước khác trước khi phân tích. Tôi đếm số lần mỗi vòng lặp, số trạng thái, chi phí sort, thao tác trên data structure và memory phụ. Tôi phân biệt worst-case với average-case khi data structure có assumption, đồng thời nói rõ có tính input storage vào space complexity hay không.

Nếu solution O(n²) không phù hợp, tôi tìm xem có thể đổi repeated work thành lookup O(1), sort rồi scan, dùng monotonic structure, prefix state hoặc giảm trạng thái DP không. Tôi không đánh đổi correctness hoặc readability chỉ để giảm một hệ số hằng khi constraint chưa yêu cầu. Sau tối ưu, tôi re-check edge cases và bảo đảm implementation khớp với complexity đã nói.

**Tín hiệu cần thể hiện:** biết chọn trade-off theo dữ liệu, không đọc Big-O một cách máy móc và hiểu chi phí thực tế của cấu trúc dùng.
