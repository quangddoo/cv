# Embedding Model Đổi khiến Search Result thay đổi

## ⚡ Tóm tắt ngắn (30s)
* **Symptom**: upgrade embedding model → recall changes. Users see different results.
* **Migration plan** (zero downtime):
  1. Add column `embedding_v2`.
  2. Dual-write: new ingests both v1 + v2.
  3. Backfill: re-embed historical data → v2.
  4. Shadow read: query both, compare.
  5. Cutover: switch read to v2.
  6. Cleanup: drop v1.
* **Eval gate**: only cutover if v2 recall ≥ v1.

## 💻 Quality gate

```python
def compare_models(v1_results, v2_results, golden_set):
    """Compute recall difference."""
    recall_v1 = sum(1 for q in golden_set if q.expected in v1_results[q.id]) / len(golden_set)
    recall_v2 = sum(1 for q in golden_set if q.expected in v2_results[q.id]) / len(golden_set)
    return recall_v2 - recall_v1

# Gate: cutover only if recall_v2 >= recall_v1 - 0.03
diff = compare_models(...)
if diff < -0.03:
    raise Exception("V2 regression, do not cutover")
```
