# AI Trả lời Đúng nhưng Không Explain được Nguồn

## ⚡ Tóm tắt ngắn (30s)
* **Symptom**: enterprise RAG answer correct but no citation → user can't verify, compliance issue.
* **Solutions**:
  1. **Citation enforcement** in prompt.
  2. **Citation validator** (check each citation exists in retrieved chunks).
  3. **Inline citation** in response: `[doc:X]` markers.
  4. **UI link**: clickable citations open source doc.
  5. **Confidence score** based on similarity.

---

## 💻 Citation enforcement

```java
private static final String SYSTEM = """
    Trả lời từ CONTEXT. Mỗi tuyên bố factual PHẢI có citation định dạng [doc:UUID chunk:N].
    
    Ví dụ:
    "Chính sách hoàn tiền 14 ngày [doc:abc chunk:3]."
    
    Nếu không tìm thấy, từ chối.
    """;

public RagResponse answer(String q, List<Chunk> chunks) {
    String response = chatClient.prompt()
        .system(SYSTEM)
        .user(buildContext(chunks) + "\n\nQ: " + q)
        .call().content();
    
    // Validate citations
    var validation = citationValidator.validate(response, chunks);
    if (!validation.valid()) {
        log.warn("Invalid citations: {}", validation.invalidCitations());
        // Retry with stricter or use raw response with warning
    }
    
    return RagResponse.builder()
        .text(response)
        .citations(extractCitations(response))
        .sourceDocs(chunks.stream()
            .map(c -> SourceDoc.from(c)).toList())
        .build();
}
```

## ⚠️ Interviewer

**"Legal team wants ALL responses have citations. Implement?"**
1. Strict prompt + few-shot examples with citations.
2. Validator: reject response without citations; retry.
3. UI: render citations as clickable links.
4. Audit: log citation per response.
5. If can't find source → refuse rather than answer.
6. Eval suite: include citation presence as metric.
